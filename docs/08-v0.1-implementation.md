# Stap 8 — PolyYaps V0.1

## Doel

De eerste werkende productversie van PolyYaps valideert de app-shell en de belangrijkste navigatie vóórdat de learning engine, IndexedDB en volledige lescontent worden aangesloten.

## In V0.1 gebouwd

- React + TypeScript + Vite basis
- mobile-first app shell
- Airbnb-modern design tokens uit Stap 6
- Home-dashboard
- bottom navigation met vier tabs
- 30-dagen Learning Path
- Smart Review mock
- Progress-dashboard met skills en mastery
- Dag 9 lesdetail als focus-flow
- eerste PWA-manifest
- responsive desktop preview die de mobiele app centreert

## Bewust nog mock-data

V0.1 gebruikt mock-progressie zodat eerst de UX wordt gevalideerd.

Nog niet aangesloten:

- IndexedDB
- echte user progress persistence
- mastery engine
- spaced repetition scheduling
- echte audio
- microfoon / speech recognition
- volledige lesinhoud
- service worker/offline cache
